# The Dog Ate My Homework: Funniest Excuse

A one-line excuse from a dog caught eating the homework, written by a
small deterministic program.

`main.ts` writes a single line to `/output/entry.txt`: the homework was
due today, so the dog turned it in early — inside itself. The program is
fixed — no clock, no randomness, no network — so it produces exactly the
same bytes on every run, and it checks the line against the competition
gate (one line, 1–200 characters) before writing anything.

Run it with Node 22:

```
node main.ts
```
